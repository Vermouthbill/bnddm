v0.2：蓝色区域改用连通分割，裁切仅保留气泡内部，韩语优先识别；文字和时间分离。这仍然不代表已经自动识别所有类型消息。

一个蓝色区域对应一条候选气泡。录屏第几秒不等于消息发送时间。 实验不会编造发送时间，也不会自动删除重复内容。识别文字可修改后导出为 JSON 草稿。

这是独立实验程序，不是完整自动归档 App。Tesseract.js、韩语模型和 WASM 文件由 GitHub Actions 在构建时取得并随本站发布，正常运行时 OCR 在本机执行；首次访问必须联网加载静态资源。iOS 浏览器可能因内存限制中断，建议先用测试图。不要将付费 DM 素材上传到公开 GitHub 仓库。
