  1. 先在「备份」页导入模拟消息，确认六人聊天和日期跳转正常。
  2. 把网页用 Safari「添加到主屏幕」，关闭 Safari 后从桌面重新打开。
  3. 导出一次 JSON 备份，并确认它出现在 iPhone「文件」App 中。
  4. 用自己制作的短模拟聊天录屏测试关键帧和 OCR 待核对队列。
  5. 不要把真实 Weverse DM 导入这一版。
自然聊天型中文翻译是固定产品规则，但 Beta 0.3 还没有联网 AI 翻译，也不会把内容发送到任何翻译服务。
